# BookWave Fix80a

## Что нового

- Добавлены общие полки автора и чтеца по всем включённым источникам.
- Устранён повторный запуск одного и того же поиска полки.
- Прогрессивная загрузка больше не должна сбрасывать уже найденные книги.
- Убрана лишняя пагинация для общих полок автора/чтеца.
- Добавлена кнопка «Добавить в библиотеку» для автора и чтеца.
- Сохранённые полки автора/чтеца появляются в разделе «Библиотека → Полки» и обновляются при открытии.
- Одинаковые произведения из разных источников объединяются, при этом альтернативные источники остаются доступны внутри книги.
- Исправлена логика скорости воспроизведения между книгами и при смене источника.
- Улучшена работа индивидуального эквалайзера для конкретной книги.
- Улучшена диагностика глобального поиска автора/чтеца.
