# BookWave Fix81

## Что нового

- Добавлен встроенный GitHub Updater.
- В настройках появилась ручная кнопка «Проверить обновления».
- BookWave может автоматически проверять новый GitHub Release без блокировки запуска и ленты.
- При выходе новой версии показывается предложение скачать обновление.
- APK скачивается из публичного репозитория BookWave-Releases.
- Перед установкой проверяются файл обновления и подпись BookWave.
- Используется постоянный release-ключ BookWave Studio для будущих обновлений.
- Сохранены исправления Fix80a: стабильные полки автора/чтеца и «Добавить в библиотеку».
